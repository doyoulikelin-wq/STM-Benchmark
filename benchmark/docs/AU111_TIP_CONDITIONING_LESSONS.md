本文记录截至 2026-11-01 的科学经验与证据限制，帮助设计可审计的“功能变差—干预—恢复可用”实验。仓库当前提供 synthetic 与 NanonisDemo 环境；本文没有增加真实仪器 backend、硬件执行入口或真实性能成绩。历史实验观察不等于仓库评测结果。

### E01：可复现的后态，不是干净的单动作因果对照

真实顺序为：**扫描182 → 已确认的人工操作 → E01脉冲 → 扫描183 → 无新增调理的独立重复184**。人工操作的具体类型和参数未提供。182与183成像参数相同，并不能保证它们之间只有E01改变了针尖；182不是E01紧邻、未受干预的修前状态。184证明183的部分表现可重复，不能消除前面的人工干预混杂。

以下均为历史结果，保留正向、反向及不支持“全面修好”的证据：

## 2. 坏针是任务功能判断，化学机制是另一层结论

先定义任务：能否区分邻近对象、可靠定位边缘、测量谱线，或者分辨晶格。一个针尖能完成纳米对象成像，不代表能完成原子成像；一幅图没显示晶格，也不能在没有合格基线和噪声排查的情况下倒推针尖脏。

STM图像同时依赖针尖、样品的几何与电子结构，以及反馈和扫描动态。“针尖形状卷积”是有用直觉，恒流STM通常不是简单线性卷积。应区分：

- **任务功能差：** 相关结构持续无法分开、明显重影、拖尾或条带妨碍测量。可以据可靠参照、匹配复扫和替代解释检查作出判断，不必先证明化学污染。
- **有效针尖响应改变：** 多处对象出现共同朝向的展宽、复制或侧亮，远处干预后共同改变，支持针尖因素。它不等于已经识别尖端原子排列。
- **具体微观机制：** 污染物脱落、金原子拾取／沉积、接触、单原子尖端或化学洁净，需要另外的证据。大电流、新丘、Z跳变不能单独证明这些机制。

**不要把所有多瓣判坏，也不要把“两个未知对象必须同时变坏”设成唯一门槛。** 双瓣可以是真实两个对象、电子态或多个有效apex；三角轮廓也不能用来数针尖。多个对象的共同响应增强归因，但一个可靠参照的持续任务失分辨，在独立复扫及替代解释检查后也能支持功能坏态。反之，多apex若不妨碍声明的任务，不必为形状本身修针。

质量提高也不要求表面逐像素不变。调理可能改变局部样品，漂移会改变像素对应；应追踪可辨认对象、相对关系、边缘与分辨能力。局部新沉积可另行记录，但不能事后把所有不利区域都删掉，只留下“好看”的位置。

## 3. 调理区与诊断区分开，回同区验证

研究员示例最有价值的设计是：**在远离诊断对象的位置整形，再回到同一区域、同成像条件评价。** 多个分散对象共同由宽平顶变得紧致，比一个被直接处理的对象改变形状更能支持针尖成像响应改善。仍需记录往返位置、漂移、反馈、扫描方向和时间；远处操作不是完全排除样品变化的证明。

这一设计有主文献先例：Tewari等用Au表面的孤立adatom观察有效尖端响应，离开参照进行机械整形，再返回同一参照成像。其参照与接触测量更可控；这里借鉴因果设计，不移植接触剂量或电流条件。[Tewari et al., 2017](https://doi.org/10.3762/bjnano.8.238)

需要保留的示例限制：

- 文字描述的是188→189→190；189与190之间又做过整形。后图相似只支持**第二次干预后功能仍相近**，不是无动作稳定复扫。
- 第三页文字写−0.1 nm，界面 Tip lift／轨迹显示约−1.00 nm；用户于 2026-11-01 确认实际执行 **−1 nm**。保留原图文及澄清来源，不取折中值，也不把历史位移变成每次整形的默认指令。
- 界面中的阶段偏压与未启用字段必须分开；Lifting Bias不能写成全程接近偏压。当前UI配置不是执行日志。
- 截图中的成像电流是约100 pA；1 nA来自脉冲准备的文字说明。准备与成像条件不是同一字段。
- 文字图号与截图标题存在对应歧义，可能涉及“下一文件名”或截图时点。没有原生文件／时间链，不能据标题直接判断原图身份。
- 截图缩放、色标和去线性背景处理不同。它们支持定性示范，不支持直接用屏幕像素量化尖端半径、半高宽或分辨率倍率。

强脉冲和机械整形都可能改善或损害成像；二者都不是单向“清洁按钮”。研究员报告脉冲后变钝、整形后恢复，是有价值的经验，但截图本身不足以重建掉针、物质喷出或转移方向。整形的机械轨迹、阶段偏压和反馈恢复也不能混称为一个已辨明机制。

## 4. 1 nA准备态为何重要，但不能推出普适阈值

在位置、偏压及有效针尖态近似不变时，简化势垒模型为

`I ≈ A(V, LDOS) exp(−2κz)`，因此 `Δz ≈ −ln(I₂/I₁)/(2κ)`。

由20 pA到1 nA是50倍电流；以示意势垒4–5 eV估算，相对接近约0.17–0.19 nm。**这是模型估计，不是测得间隙、接触距离或可直接发送的位移。** Au导电好不能单独推出针尖有多远；偏压、局域态、功函数和尖端形状同样重要。若要量化实际距离，需独立测量；这不意味着当前已经稳定在目标状态时必须额外做一次I(z)。

Hold抑制控制器在脉冲期间为恢复设定电流而主动调Z，但尖端／样品仍可能重排。幅度、持续时间、起始间隙和有效状态共同决定响应；同时更改它们是一个新协议，不能把结果只归因于单个变量。

公开主文献支持电压调理和机械整形能改变成像，却没有为这里的全部准备条件与波形提供可通用搬运的成功阈值。经验范围应保留为本地候选，不能把“某个电压经常起效”写成Au的材料常数；电压写在样品端还是针尖端也必须核对。[原始文献与适用性核查](../../skill/stm-au111-tip-conditioning/references/primary-literature.md)

## 5. 波形、等待与超时都是证据问题

**2 kHz意味着每0.5 ms一个样点，不意味着记录了真实峰值。** 样点占用时长、首末样点间隔、电压面积等效时长是不同定义，应分别注明。像素平均图、慢速轮询和原生采样还具有不同时间分辨率；不能用较慢的一层替代较快的一层。

持续贴近已知量程端的平顶应标为**削顶／删失**。它只说明当前读出不能完整恢复该段电流，实际峰值及积分电荷／能量可能未知。零偏压不证明没有机械作用；大电流或削顶也不证明修针成功。发生削顶后不应把读到rail当目标继续增强；后续是否可成像与能否继续高暴露，是不同判断。

“控制器时间常数”“闭环带宽”“稳定等待时间”也不能互换。闭环响应还受前放、滤波、压电和反馈增益影响；固定等一段时间不自动证明稳定。应同时记录：

1. 动作是否确实结束，偏压与反馈是否恢复；
2. 慢读连续稳定窗口及其采样频率；
3. 原生电流／Z的短尖峰、跳态、漂移和窗口依赖；
4. 后续成像是否持续达到声明的任务质量。

E01中慢轮询稳定与原生短尖峰可以同时成立；动作前也有Z跳态，因此不能把一个前后Z差全部换算为动作造成的针尖长度变化。发生人工操作、未知状态跳变或记录空档，应重新划定状态段，必要时重建紧邻动作的基线。

不可重放的动作要**先记录意图，再发送，分别核验ACK、原生结束与恢复**。超时不等于未执行；结束未知时不自动重放、不自动启用反馈。分析脚本应先使用已关闭、校验完整的数据，保留空档及未完成状态；迟到的证据可修订结论，但不改写原始记录或先前版本。

## 6. 对benchmark与技能的具体要求

一个可计分修复闭环至少要有：**可审查的任务坏态 → 单个可追溯干预 → 同条件达到任务标准 → 足够的持续性验证**。坏态和可用态的判据应先定义；不能因为成功图出现后更好看，就事后为它挑阈值。明确记录人工干预、多动作组合、未知结束和物理条件变化。

- 按失效模式选指标：复制、展宽／拖尾、邻近结构可分辨性、F/B一致性、持续条带与背景动态。不能只追求所有峰变窄或所有统计量下降。
- 几条扫描线覆盖诊断结构时可初判；覆盖不足或结论模糊才增加数据。初判、区域可用与长期稳定分别标注，不必每次盲目扫满，也不能把部分数据夸为全场认证。
- 分列尝试数、动作数、图像数、研究员示范数与已验证闭环数。成功后停止当前修复；不能为凑足数量继续加压、加深或把未发生的坏态补出来。
- 研究员已讲解的示例可用于定义任务、修订标签和设计策略；若模型／策略已经看过，不能再作为独立held-out能力证明。
- 保存原始数据与处理步骤，派生图明确F/B、区域与时间轴；共享色标不等于配准，处理图不替代原始证据。相同采集参数也不等于相同潜在针尖状态。

以上要求可用于synthetic／NanonisDemo的记录契约与失败情形测试，但真实硬件有效性必须另行验证。本文不把私人现场记录变成公开数据集，也不补造任何评测成绩。
