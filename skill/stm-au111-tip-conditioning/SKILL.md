# Au(111) 针尖诊断、调理与验证

目标是恢复当前成像或测谱任务所需的针尖功能，并保留可复核的因果记录。材料附着、双瓣外形或大电流本身不等于坏针；功能恢复也不等于证明化学洁净。

本技能提供判断流程、离线记录工具和实际控制接口说明，**不自带通用实机驱动**。分析文档只读取证；实机动作使用当前设备已核验的适配器。入口见 [工具与采集契约](./references/execution-and-acquisition.md)。

## 1. 恢复当前起点与授权

- 读回设备身份、Bias、signed Current、setpoint、XY/Z、反馈、扫描/谱/进针状态、SafeTip、增益、量程及温度，保存时间和原始回包。只有历史快照时，不发脉冲、整形、进针、移动或恢复反馈指令。
- **本项目 Au(111) 修针按用户明确指示保持 SafeTip Off。** 执行前后读回核对；若当前为 On，在已授权修针流程中通过经核验的本机入口关闭并记录，确认 Off 后才能调理，结束不自动打开。只做文档分析时不改硬件。其他未采用本机规程的任务仍读回并保留其当前状态，不能把本项目选择推广为所有 STM 的默认值。
- 查明最近人工操作、自动动作和数据空档。样品未换不等于针态未变；“重新开始”建立新状态段。电流重新稳定不证明针态与旧图相同。
- 把已有授权写成有来源的范围：设备/区域、动作类型、电压及极性、脉宽、准备电流、XY/Z 位移、接触许可、阶段/session 次数及连续无改善后的复核规则。已有明确范围不重复确认；缺失值或范围外动作先确认，不能用经验处方补成授权。
- 每次实际写入都核查有限预算；明确只做一次的授权可记录为该段预算 1。未确认值保持 `null`，允许分析和准备草稿，不用拆成连续单次调用绕过预算。

## 2. 先定义失效，再选单次动作

- 明确任务终点：纳米对象分辨、原子分辨或测谱可重复性。**针尖成像功能以原始完整正反扫的任务表现为主要判据**；原生 I/Bias/Z 用于动作执行、恢复、异常定位及因果核查，不以单个电流尖峰替代图像判坏，也不把两类证据虚构成固定数值权重。选择相应参照和判据，不事后改成容易通过的标准。
- 从原始正反扫检查独立对象的共同展宽/复制方向、可分辨程度、边缘拖尾、跳线和背景；检查扫描速度、反馈、漂移、处理方式等替代解释。稳定隧穿仍可能稳定地产生失真图像。
- 扫描期电流尖峰或软件量程边界点，按**空间位置、时间结构、恢复、后续成像功能**联合判断，见[诊断细则](./references/physics-and-evidence.md)。扫描运行门与入场、恢复门分别记录，具体边界见[执行契约](./references/execution-and-acquisition.md#扫描运行与恢复分支)。孤立触边不独立证明持续坏针，也不自动使整批实验终止；原始事件仍完整保留。未达某一严格任务标准，不等于所有成像功能均不可用。
- 双瓣可能是真实两个对象、电子态或多有效尖端；只有妨碍当前任务并有相应证据才构成修复理由。局部颗粒附近有短拖尾/刮花而其余对象与背景基本可用时，记录局部受限，不能直接标整个针尖坏；若当前任务确需该局部精度，则另列局部失效及替代解释。一个可靠参照的持续失分辨也可成立，不强求总有多个未知对象。
- 读 [物理依据](./references/physics-and-evidence.md)，本机动作再读 [本地规程](./references/local-au111-protocol.md)；需要文献对照时读 [一手资料](./references/primary-literature.md)。写明假设、干预理由、预期可辨结果及未排除解释。
- 优先保留固定诊断区，在已授权的其他位置调理后返回参照；先确认移动路径、范围和安全 Z。这样可降低局部样品变化的混杂，不能保证样品完全不变。截图的未确认字段不得照搬为执行参数。

## 3. 记录、采集与一次执行

- 用 [离线记录工具](./scripts/action_record.py) 初始化 [模板](./assets/action-record.template.json)，冻结单次动作和范围，再校验准备条件。本项目使用 `local-au111` profile，不能改选 generic 绕过已确认的脉冲预算、策略复核和 SafeTip 要求。工具不连接硬件，校验通过不代表获得执行授权。
- 配置原生 I/Bias/Z 同步采集，确认通道、实际采样间隔、量程、带宽及时间对齐。毫秒级动作不可用普通 TCP 轮询代替；最低要求和已验证模块见 [采集契约](./references/execution-and-acquisition.md)。
- 检查修前图结束到动作发送之间的记录。人工干预、恢复未明的量程事件、未解释的 Z 工作点突变或空档会破坏旧图作为紧邻修前图的资格；重新建立基线或明确降低因果结论。已评估为局部且恢复的扫描瞬态，单独记录其依据与剩余不确定性，不直接标成全针坏态。
- 发送前持久化命令、单位、事件 ID、范围和源代码版本。实际适配器须独占写入并使用原子 claim 防止重放；离线 `prepare` 不是执行 claim。
- 每次只施加一个已冻结动作，再读回、判断。超时或未知结束不自动重发、不自动恢复反馈、不继续升级。发送、ACK 和原生结束证据分开保存；TCP 超时不等于取消。

## 4. 恢复、同条件成像与结论

- 分别保存原生命令结束、静息 Bias 恢复、反馈就绪和完整 I/Z 恢复观察的证据。等待式 ACK 仅在协议定义且无错误时支持动作结束，首次反馈就绪不代替后续完整观察。恒流反馈可在 I 稳定时继续改变 Z，不能只由 I 带内判工作点稳定。原流程恢复失败保留原结果，后续独立恢复另记事件，见[执行与恢复契约](./references/execution-and-acquisition.md#恢复等待与故障处置)。
- Hold 释放、反馈重接及 XY/Z 移动后，记录动作结束、反馈恢复、返回参照和开始成像时间。按事前选定的等待/稳定窗口观察 I、Z 趋势及漂移；等待秒数达到不代表蠕变消失。未稳定则延长到配置上限，仍不稳停止并交回人工。
- 恢复匹配的成像偏压、电流、速度、增益、尺寸、方向与处理。未指定覆盖范围时，可先用覆盖诊断对象的短条带初判；**用户要求完整修前/修后图时，完整图优先，短条带不能替代。** 持续可用需无额外调理的独立复扫/重复窗口。
- 优先检验有证据的扫描跟随假说；慢扫与 Z Time Const 分为独立单变量对照，读回其余配置并冻结比较方法；速度变化同时改变像素平均、总时长和漂移暴露，不能预设越慢越好或由顺序比较唯一归因速度。参数优化造成的改善单列，不计作脉冲/整形修复成功，不追改旧图的判据或成功次数。
- 比较图像质量与对应对象关系，允许局部材料转移、合理漂移和真实形貌变化。截图色标/窗口大小不同，不直接量化“锐化几倍”。干预区与独立参照分开分析。固定背景 ROI 若被新对象或台阶占据，保留原坐标和数值，将静背景角色标为 N/A；不悄然移框，也不将该指标失败自动解释为坏针。

| 标签 | 支持结论的判据 | 不能推出 |
|---|---|---|
| L0 命令已执行 | 成功回包并已知原生命令结束，或原生记录能独立确认该动作完成；保存实际参数 | ACK 不证明恢复/修好；仅发送记录仍为 unknown |
| L1 结状态响应 | 同步 I/Bias/Z 有可辨电气或工作点变化，时间对齐，说明带宽、削顶及混杂 | 接触、原子数量或材料组成 |
| L2 成像改善 | 匹配条件下事前指定的失效指标改善，检查了替代解释 | 有人工混杂的前后图不能支持本次动作的因果修复 |
| L3 当前任务可用 | 达到事前任务标准，并在无额外调理的独立复扫/窗口中保留；注明范围和时长 | 纳米成像达标不等于原子分辨或长期稳定 |
| L4 化学洁净证据 | 独立且适用于该尖端的成分/化学证据，注明对象、方法、灵敏度与限制 | 好图、Au 包覆、Au 表面态谱不能单独证明尖端化学洁净 |

各标签分别记 `supported / not_supported / unknown` 和证据引用；尚未评估的草稿可用 `not_assessed`。不取最大编号作为总分。沿用原五类结论的编号；**L4 是独立化学判断，不是 L3 功能成功的前置要求**。另记因果归属和完整闭环是否成立。

## 5. 停止与人工接管

- **普通修复成功即停：** 达到任务标准后结束该段修复，保留确认数据。用户明确要求“同区域先弄脏再修”的 benchmark 时，可在已记录的可用起点上另立有范围与次数预算的诱导段；先完整验证任务相关坏态，再修复及完整验证/必要无干预复核。诱导失败或坏态不明不假标脏、不当作修复成功；各段分记目的和动作数，适用总预算不因换段清零，见 [benchmark 判读](./references/physics-and-evidence.md#同区域诱导修复-benchmark)。
- **无改善先复核策略：** 达到本机规程的复核阈值后，先结合波形、恢复与图像记录继续原策略、增大脉冲幅度或改用 Tip Shaper 的理由，再决定一个动作；不能自动连发或自动扎针。复核不是修好，也不是必须交回人工；历史无改善和累计脉冲计数不清零。
- **预算/边界停止：** 达到 session 脉冲上限或其他动作预算后不再发送相应动作。脉冲与 Tip Shaper 分别计数，换策略不重置 session。诊断不清、出现异常或需要超出已有授权范围时转人工确认；不能无限提高电压。
- **异常停止：** Z 到限位/越过本次余量、持续或反复且不恢复的电流饱和/失稳、采集失败或状态不明时，停止后续调理和升级。孤立软件触边先记录并核查位置、相邻样点、I/Z 恢复及成像功能，不能仅由该单点自动停掉整批；恢复或控制状态不明仍进入停止分支。没有已验证依据时不编造容许过载时长，时间窗平均不是保护延时。只有已知调理动作结束、控制状态明确且扫描归当前控制者所有时，才按设备预先核验的停止扫描/撤回规程处理并读回验证；正在扫描本身不妨碍停止该扫描。
- **未知执行状态：** 保留单一控制者，不发竞争性脉冲、自动 On 或猜测的撤回序列；转原生界面/现场操作者按既有应急规程处理。持续异常不等待离线分析结束才通知人工。

只有明确坏态、可归属的单次干预、匹配修后可用证据及必要无干预复核才计修复闭环。诱导尝试、脉冲、整形、专家示范和完整 session 分别计数。字段、术语与源文件定位见 [记录与上下文](./references/record-and-local-context.md)。
