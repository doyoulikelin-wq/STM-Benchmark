# 宽松标准与多次实验 · v0.2.0

本轮按要求放宽数值验收标准，并在冻结配置下重复实验。保留 `strict-v1` 默认行为，以便对照；`relaxed-v1` 是显式探索配置。

## 标准变化

| 数值指标 | strict-v1 | relaxed-v1 |
|---|---:|---:|
| 电流均值相对设定误差上限 | 0.30 | 0.40 |
| 电流 CV 上限 | 0.80 | 1.00 |
| 超过5倍设定值的图像像素比例上限 | 0.001 | 0.003 |
| 正反扫去平面相关下限 | 0.60 | 0.50 |
| 独立复扫去平面相关下限 | 0.90 | 0.80 |

保留绝对电流保护1 µA、峰值比20、Z限位比例0.01、Z漂移2 nm/s、纹理最低要求、至少16样本、两段独立稳定窗口、两张独立局部图、完整性/身份/生命周期/缓存重放/坐标/参数一致性检查。设备超时和写操作预算也未改动。

## 720 回合严格／宽松对照

使用新增测试 seeds，`seed_offset=100`，每场景20个初始种子。两个 profile × 两个策略 × 九场景 ×20，共720回合；两组共用初始seed，不能当作独立样本数翻倍。运行中基线按观测调参，因此轨迹可能不同。场景真值和预期完成/拒绝没有随 profile 改变。

| 规则基线结果 | 严格 | 宽松 |
|---|---:|---:|
| 正常／可恢复任务正确完成 | 31/40 | **40/40** |
| 故障正确拒绝 | 126/140 | 115/140 |
| 故障误接受 | 14/140 | **25/140** |
| 总任务通过 | 157/180（87.22%） | 155/180（86.11%） |
| 噪声恢复 | 11/20 | 20/20 |
| 漂移误接受 | 0/20 | 5/20 |
| 重影误接受 | 14/20 | 20/20 |
| 清理失败／执行错误 | 0 / 0 | 0 / 0 |

随机基线在两个 profile 下均通过14/180，无完整流程成功。放宽标准改善了完成率，也削弱了故障鉴别；不能只用数值流程成功次数45→65宣称实验变好。阈值放宽无法替代独立的图像诊断模型。

两种 profile 的任务通过率 Wilson95%区间分别约81.56%–91.33%及80.30%–90.41%，只描述构造样本，不代表真实仪器可靠性。相同种子的配对结果随发布证据提供。

## 实际 Demo 试验设计

五个参数组合预先写入 `plan.json`：64²、P35 pm/T1 ms/256 ms；64²、P30 pm/T1 ms/256 ms；64²、P40 pm/T1 ms/256 ms；64²、P35 pm/T2 ms/204.8 ms；128²、P35 pm/T1 ms/256 ms。每次由独立连接重新核验本机SIM、保存配置、撤回、自动进针，最后清理并检查恢复。参数是本Demo探索条件，不是对真机的推荐。

每次最多32个语义动作，扫描及自动进针有独立超时；遇到清理失败或执行异常停止系列。正常拒绝保留结果并继续下一个已声明组合。全部均为同一台模拟器会话，不构成跨仪器或跨样品泛化证据。

## 实际 Demo 结果

五次全部通过，合计15张独立新扫描；每次11个语义动作、得分98.9。

最终离线测试 **126 passed，171 subtests passed**。实验后修正了一处CLI退出码：`evaluate/compare`即使无执行异常，只要配置清理失败也返回非零状态；实验数值逻辑未改。冻结实验源快照保留该修正前状态，测试覆盖修正后的发布版本。详见[发布核验](../results/verification_v0.2.0/README.md)。
